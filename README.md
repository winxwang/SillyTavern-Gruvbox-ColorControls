# SillyTavern Gruvbox Color Controls v1.4

SillyTavern Gruvbox theme color and background controls extension.

## Contents
- `GruvboxColorControls/` — extension source and manifest
- `Gruvbox-Material-Violet-可视化调色版.json` — companion theme preset

## Install
1. Copy `GruvboxColorControls` into your SillyTavern `public/scripts/extensions/third-party/` directory (or install it using the extension manager's local extension workflow if supported by your SillyTavern version).
2. Import `Gruvbox-Material-Violet-可视化调色版.json` from the Themes panel.
3. Follow `GruvboxColorControls/README.txt` for configuration details.
