Gruvbox 主题可视化调色与背景管理面板（v1.4）

新增/优化：
- 原生颜色选择器
- HEX 色值精确输入（例如 #69A54B）
- R / G / B 三个通道的 0-255 数值输入
- 常用 Gruvbox、草绿、蓝色、紫色、暖色和灰阶色板
- 复制 HEX 色值
- 用户消息背景、AI 消息背景分别调整
- 页面和聊天区域背景颜色与透明度分别调整
- 全局文字、用户文字、AI 文字、人物对白颜色分别调整
- 自动保存设置，重新打开酒馆后恢复
- 恢复默认颜色
- 从本地选择多张酒馆背景图片，缩放压缩后自动保存
- 背景图片功能独立开启/关闭按钮
- 自动切换开关、切换间隔、上一张/下一张、图片预览与单张移除

安装：
1. 解压 ZIP。
2. 将 GruvboxColorControls 文件夹复制到：
   SillyTavern\public\scripts\extensions\third-party\GruvboxColorControls
   如果文件夹已存在，请覆盖旧版文件。
3. 在酒馆中启用 GruvboxColorControls 扩展。
4. 导入并启用 ZIP 中的 Gruvbox-Material-Violet-可视化调色版.json 主题。
5. 刷新酒馆页面，在“扩展”设置里打开调色面板。

颜色输入说明：
- 可点颜色方块打开系统取色器。
- 可直接输入 HEX 色值，例如 #80C060；输入有效的 3 位或 6 位 HEX 即会应用。
- 可分别编辑 R、G、B 数值，范围均为 0-255。
- 色板点击后会应用到当前正在编辑的颜色项；每个颜色项下方也有独立色板。
- 透明度 0% 表示完全透明，100% 表示不透明。

说明：此扩展针对常见 SillyTavern 扩展设置结构编写，尚未在用户本地实例中实机测试。建议先备份旧扩展文件夹和主题 JSON。

背景图片功能：在扩展设置的“酒馆背景图片与自动切换”中选择图片；导入后会自动启用。点击“关闭背景图片功能”可临时停用并恢复原背景，图片列表不会删除。开启“自动定时切换背景”后，至少需要两张图片；间隔为 1–1440 分钟。清空图片列表会移除保存的图片数据。为控制设置文件大小，图片会缩放至最长边 1920 像素并压缩为 JPEG，最多保留 30 张。


【v1.3 新增】
- 聊天界面功能按钮颜色：可分别设置按钮背景色、背景不透明度、图标/文字色、悬停背景色和边框色。
- 支持取色器、HEX、RGB、快捷色板，调整即时生效并自动保存。
- 设置面板内含按钮预览。删除/取消等警示按钮尽量保留原本警示色。


【v1.4 新增】
- 输入框自动隐藏开关：发送消息后自动收起编辑区。
- 收起时只显示发送图标和展开图标；点击展开可继续正常编辑。
- 设置会自动保存；关闭开关会恢复酒馆原本的输入区域。
